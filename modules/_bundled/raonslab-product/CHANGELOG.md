# 변경 이력

## [0.5.1] - 2026-09-29

### Changed

- 홈 제품 증거에서 두 사례가 각각 무엇을 보여 주는지 한 줄로 설명 — RAON Hub 는 지금 보고 있는 이 사이트이며 기존 서비스에 AI 요청·결과·후속 지시 흐름을 확장한 사례, MOBILE_STOCK 은 업무 흐름 구현과 실주문 차단 검증을 보여 주는 자체 개발 사례. RAON Hub 의 "확장 방식" 칸은 이 설명 줄로 합침
- MOBILE_STOCK 실제 화면을 휴대폰에서도 읽을 수 있는 크기로 키우고(390px 화면 기준 약 100px → 152px 폭, 비율 유지), 누르거나 키보드로 선택하면 같은 원본 이미지를 열 수 있도록 개선. 캡션·이미지 원본은 그대로 유지
- MOBILE_STOCK 화면 속 앱 이름이 Symphony 임을 홈에 한 번 표시
- 홈 사례 영역의 "기술 근거 보기" 링크 문구를 도착지에 맞게 "사례 상세 보기"로 변경

### Compatibility

- 상담 접수 상태(닫힘), 홈 7섹션 순서, Hero 문구, 정보·정책 분류, 안내 문서(Page) 본문은 그대로 유지. 기본 템플릿·코어 변경 없음

## [0.5.0] - 2026-09-29

### Added

- 홈 두 번째 공개 사례로 자체 제작 모바일 모의투자 앱 MOBILE_STOCK 을 추가 — 실제 화면(예시 데이터)과 "모의투자 · 자체 제품 · 예시 데이터" 표기, 검증된 범위(새 계정에서 첫 모의 원화 매수까지, 실제 주문 경로 없음)와 아직 미검증 항목을 함께 표시
- 홈 두 번째 섹션에서 두 제품(RAON Hub·MOBILE_STOCK)을 미리 보여 주어 휴대폰에서도 두 화면 안에 실제 제품 증거를 확인할 수 있도록 개선

### Changed

- 홈 첫 화면을 승인된 제목·한 줄 설명·"업무 입력 → 제한된 실행 → 검증 → 결과" 4단계 흐름으로 단순화하고, 장식용 상태 줄·범례를 제거
- 온라인 상담 접수가 열리기 전에는 홈의 주 행동을 "검증된 RAON Hub 사례 보기"·"도입 절차 보기"로 바꾸고, 접수가 열린 것이 확인될 때만 상담을 주 행동으로 표시
- 상위 메뉴의 구축 상담 진입점에 접수 준비 중 여부를 클릭 전에 표시
- 휴대폰·태블릿 홈에서 겹쳐 쌓이던 제품 메뉴 줄과 섹션 바로가기 줄을 없애고 기본 헤더·메뉴(드로어) 하나로 탐색하도록 정리
- 홈 첫 화면 바로 아래에 RAON Hub 실제 증거 줄(실제 실행·검증·확장 방식·범위)을 두어 첫 스크롤 안에서 실제 제품 근거를 확인할 수 있도록 개선
- 제공 서비스를 업무 한 개 실증·맞춤 Agent 구축·운영·개선 세 줄로 줄이고, 줄마다 입력·결과물·고객 준비 사항을 한 줄씩 표시
- 문제 설명을 "적합한 업무 / RAON이 맡는 일" 두 열로 바꾸고, 다른 AI 도구의 한계가 아니라 구축 책임으로 차이를 설명
- 구현 사례를 사례마다 "검증됨 / 아직 미검증"을 먼저 보여 주는 형태로 바꾸고, RAON Hub 는 구성(기존 G7 서비스 + RAON 확장 + AI 작업공간)과 함께 기술 근거를 사례 문서로 연결
- 도입 절차 5단계와 기술 소개 5개를 "범위 → 실행 → 검증 → 승인·복구" 한 줄 타임라인과 운영 원칙 세 줄로 통합
- 상담 영역의 중복 안내를 줄이고, 접수 준비 중 안내 문구를 짧게 정리. 커뮤니티·AI 작업공간 진입은 한 줄 링크로 유지
- 휴대폰에서 섹션 여백과 제목 크기를 줄여 홈 전체 길이를 약 43% 줄임(390px 기준 9,225px → 5,223px)

### Compatibility

- 정보·정책 문서 분류, 드로어 문서 메뉴, 데스크톱 상위 메뉴·푸터, 커뮤니티·안내 문서·AI 작업공간 경로는 그대로 유지. 기본 템플릿·코어·이커머스 변경 없음

## [0.4.2] - 2026-09-28

### Changed

- 휴대폰 메뉴(드로어)에서 기본 쇼핑 섹션과 기본 정보·정책 링크 대신, 상위 메뉴·푸터와 같은 11개 안내 문서를 정보·정책 두 묶음으로 표시
- 드로어의 문서 링크를 누르면 메뉴를 닫고 이동하며, 지금 보고 있는 문서가 현재 위치로 표시되도록 개선

### Compatibility

- 언어·회원·게시판 등 나머지 드로어 섹션, 데스크톱 상위 메뉴·푸터·문서 메뉴, 통화 선택기 숨김은 그대로 유지. 기본 템플릿·코어·이커머스 변경 없음

## [0.4.1] - 2026-09-28

### Added

- 정보 6종(소개·서비스·사례·기술 원칙·자주 묻는 질문·문의·상담 안내)과 정책 5종(개인정보·이용 원칙·AI 작업공간 정책·오픈소스 고지·결제·취소·환불 안내)을 하나의 분류로 묶어 상위 메뉴·푸터·문서 메뉴에 같은 순서로 표시
- 휴대폰·태블릿에서 문서 목록을 본문 위의 접힌 메뉴로 제공하고, Enter/Space 로 열고 Escape 로 닫으면 메뉴 버튼으로 포커스가 돌아가도록 개선
- 그대로 남은 기본 샘플 안내 페이지 4종(소개·자주 묻는 질문·문의·환불)을 승인된 본문으로 한 번에 교체하는 운영자 전용 명령 추가 — 사전 상태가 하나라도 다르면 아무것도 바꾸지 않고, 다시 실행하면 이미 적용됨으로 끝남

### Changed

- 데스크톱 문서 메뉴를 본문 오른쪽 열로 옮기고 스크롤해도 화면에 남도록 수정(키보드 이동 순서는 본문 다음)
- 안내 문서 11종 모두에 같은 문서 폭·breadcrumb(홈 / 분류 / 문서)·현재 위치 표시를 적용하고 발행일 줄을 숨김
- 설명 없이 값 이름만 나열한 "제공하지 않음" 목록을 한 덩어리의 작은 격자로 정리
- 공개 화면에서 통화·배송국가 선택기를 숨김(온라인 결제를 받지 않는 사이트). 이커머스 모듈·설정·데이터는 그대로 유지
- "Powered by 그누보드7" 표기를 숨기려던 동작을 제거하고 오픈소스 표기로 유지

### Fixed

- 안내 문서의 제품 목록에 편집기 기본 글머리표가 겹쳐 두 개씩 보이던 문제 수정
- 문서 메뉴가 float 로 배치되어 본문 일부만 옆에 붙고 나머지는 전체 폭으로 흘러내리던 문제와 sticky 가 동작하지 않던 문제 수정

### Compatibility

- 모바일 드로어의 기본 정보·정책 링크와 검색봇용 서버 렌더 푸터는 기본 템플릿이 확장 지점을 제공하지 않아 이번 버전에서 바꾸지 않음(문서에 제한과 제안 경로 기록)
- 기존 `/page/{slug}` 주소와 `/info/*`, `/policy/*` 호환 301 은 그대로 유지. `raonslab-ai-workspace`·상담 공개 API 변경 없음, 상담 접수는 계속 비활성

## [0.4.0] - 2026-09-28

### Changed

- 정보·정책 문서 7종의 제목·본문·발행·SEO·수정시각·version 원본을 `sirsoft-page >=1.1.2`로 전환
- 승인된 외부 Page JSON과 명시적 활성 관리자 attribution을 받아 누락 slug만 공식 Page 서비스로 원자적 생성하고 기존 관리자 편집본은 항상 보존하는 재현 가능 bootstrap 명령 추가
- product navigation과 footer를 canonical `/page/{slug}`로 연결하고 native `page/show` 확장 지점에서 RAON breadcrumb·side navigation·dark neutral presentation 유지
- `/info/*`, `/policy/*` 호환 URL은 query string을 보존하는 301로 canonical Page에 연결하고, 과거 지원 locale prefix는 G7의 `locale` query 계약으로 변환
- 배포 browser smoke는 viewport별 browser session을 재사용하고 상담 설정을 먼저 검사해 공용 API 요청 burst를 줄이며, 비-JSON 오류 응답도 상태와 content type으로 명확히 보고

### Removed

- product 소스가 중복 소유하던 문서 layout 7개, 공개 route manifest와 ko/en 본문·SEO 번역 키 제거

### Compatibility

- G7 Menu는 관리자 sidebar 전용이고 public user template이 소비하지 않으므로 public taxonomy는 product navigation에 유지
- 미설치 상태인 `sirsoft-gdpr`는 변경하지 않음. 설치 시 기본 `privacy_policy_slug=privacy`가 canonical `/page/privacy`를 소비하는 latent 계약만 검증
- `raonslab-ai-workspace`, 상담·board 공개 API에는 변경이 없으며 상담 intake 기본값은 계속 비활성

- 비식별 합성 데이터로 상담 저장·재전송·중복 충돌·관리자 상태 변경을 확인하고 흔적 없이 되돌리는 리허설 명령 추가

- 예전 상담 관리 화면 주소로 들어오면 빈 목록 대신 상담 게시판으로 안내하도록 수정

## [0.3.0] - 2026-09-28

### Added

- 서비스·사례·원칙과 개인정보·커뮤니티·AI 작업공간·오픈소스 정책을 설명하는 공개 정보·정책 화면 7종 추가
- 기존 `questions` 게시판에 합성 운영 안내 8개 질문과 depth-1 답변 8개를 적용·갱신·롤백하는 provenance 기반 Q&A 콘텐츠 명령 추가
- 기존 0.2.1 설치가 상담 전용 비활성 private board를 준비하도록 `Upgrade_0_2_2` lifecycle step 추가

### Changed

- visual pass 2에서 상품 사례·서비스·도입 절차를 코드 네이티브 미니 화면과 근거 레일로 구분
- 신규 상담 저장을 별도 product 테이블에서 G7 공식 `PostService`와 항상 비밀·관리자 전용인 비활성 board로 전환
- 기존 product 상담 admin API를 410 안내로 전환하고 상담 운영 화면을 공식 board admin으로 일원화

### Fixed

- Q&A rollback이 provenance가 소유하지 않은 답글·댓글·첨부·신고가 있으면 아무 행도 변경하지 않고 중단하도록 보강
- Q&A apply/rollback의 provenance 한정 알림 억제, topology 검증과 동시 실행 잠금으로 중복·오염을 fail-closed 처리

### Security

- 상담 board의 공개 활성화·일반 사용자 권한·검색 색인·게시글 알림·파일 업로드를 차단하고, 분류 실패 시에도 검색 비색인을 우선
- 기존 상담 테이블에 데이터가 있거나 HTTPS·동의·정책·담당자·보관 설정이 완전하지 않으면 공개 접수를 fail-closed 처리
