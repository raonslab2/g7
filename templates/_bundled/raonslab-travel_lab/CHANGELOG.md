## [0.1.3] - 2026-10-09

### Added

- 기획전 목록(`/travel/campaigns`)과 상세(`/travel/campaigns/:slug`, 사이트맵 주소 `/page/:slug`) 화면을 추가했습니다. 상세는 저장된 본문과 버전을 보여 주고, 같은 테마의 실제 여행을 여행 목록과 같은 조건으로 불러와 상품 상세·장바구니로 이어집니다.
- 본문은 서식 태그만 허용하는 정제기로 그려 링크 주소·이미지·외부 자원 요청을 남기지 않습니다. 텍스트 본문은 줄바꿈을 그대로 보존합니다.
- 상단 메뉴와 모바일 메뉴에 기획전 바로가기를 추가했습니다.

### Changed

- 홈의 고정 계절 배너를 발행된 기획전 카드로 바꿨습니다. 발행된 기획전이 없으면 섹션을 숨기고, 불러오기 실패 시 다시 시도 안내를 보여 줍니다.



- 기획전 API 를 제공하는 여행 모듈 >=0.1.3 을 요구합니다. 이커머스·Page 의존 버전은 유지하고 게시판은 아래의 수정 버전을 요구합니다.

- 실제 첨부 미리보기의 번역된 400 응답이 포함된 sirsoft-board >=1.1.3 을 요구합니다. 고정 Travel Lab 실행 패키지에서 해당 수정 버전을 보장하며 다른 사업 모듈은 수정하지 않습니다.

## [0.1.2] - 2026-10-09

### Compatibility

- 원자적 한도 검사와 접수 잠금 수정을 가진 여행 모듈 >=0.1.2를 요구합니다. 고객 화면·자산은 이전 고정 검증 버전과 같습니다. 서버의 일시적 503은 기존 오류/재시도 동선으로 처리합니다. 추가 소비 확장은 없습니다.

### Fixed

- 내 상담 요청 카드를 세로로 배치하고 그리드 최소 너비와 제목·정보 줄바꿈을 조정해 390px에서 가로 넘침을 막았습니다. 요청 ID·상태·금액과 키보드 상세 진입을 유지하며 상품명은 생략하지 않습니다. 레이아웃 내부 변경으로 공개 API·훅 및 확장 의존 버전은 유지합니다.

### Changed

- bundled 의존성의 정상 신규 설치와 실패 중단을 보장하는 코어 최소 요구 버전을 7.0.12로 상향했습니다. 기존 모듈 Service·Route·가격 계약은 바뀌지 않아 확장 간 최소 API 버전은 유지합니다.

## [0.1.1] - 2026-10-09

### Fixed

- 기존 세션 키가 있는 상태에서 저장소 쓰기·삭제가 실패해도 최신 메모리 본문과 삭제 표식을 우선해 같은 탭의 재시도 키·연락처가 되돌아가지 않도록 했습니다.

- 상담 요청 준비 결과를 네이티브 sequence 로컬 본문으로 캡처해 첫 제출의 오래된 전역 키를 제거했습니다. 서버 응답 유실 후 동일 본문·키 재시도와 소비된 빈 장바구니의 새로고침 복구를 지원합니다.
- 로그인 회원 UUID로 미확인 본문 복원을 구분하고, 성공한 명시적 장바구니 변경은 이전 미확인 본문을 폐기합니다.

### Added

- 여행 메타데이터 등록·편집의 관리 화면 계약과 후보 상품/옵션 선택을 연결했습니다. 가격·옵션 편집은 지원되는 숫자 상품 ID로 기존 이커머스 관리 화면에 연결합니다. 모듈 API 최소 버전은 리드의 0.1.1 통합 시 함께 상향합니다.
- `travelLabPrepareInquiry` 핸들러와 실제 로그인/API를 이용하는 390px·1440px 응답 유실 재현 스크립트를 추가했습니다. 다른 확장에 이 핸들러의 기존 소비자는 없습니다.

## [0.1.0] - 2026-10-09

### Added

- 밝은 톤의 여행 고객 화면 템플릿을 새로 제공합니다. 모바일(390px)부터 데스크톱(1440px)까지 같은 흐름으로 동작합니다.
- 여행 홈 화면을 추가했습니다. 계절 히어로와 검색, 지역 바로가기, 테마 카드, 기획전 배너, 추천 여행과 곧 떠나는 여행 목록을 보여줍니다.
- 여행 찾기 화면을 추가했습니다. 검색어·지역·테마·출발일·예산으로 거르고 추천순·가격순·출발 임박순으로 정렬할 수 있으며, 조건은 주소에 남아 새로고침이나 뒤로가기 뒤에도 유지됩니다.
- 여행 상세 화면을 추가했습니다. 일정을 날짜별로 보여 주고, 남은 좌석을 보며 출발일과 인원을 골라 예상 금액을 확인한 뒤 여행 장바구니에 담을 수 있습니다.
- 로그인한 고객을 위한 여행 장바구니를 추가했습니다. 출발편별 인원 변경과 빼기, 예상 합계 확인, 상담 요청 보내기를 할 수 있습니다.
- 상담 요청(테스트)과 진행 상태 화면을 추가했습니다. 요청과 상태 변화는 모두 거래 테스트로 처리되며 실제 예약·결제·환불은 일어나지 않습니다. 연결이 끊겨 다시 보내도 같은 요청으로 처리됩니다.
- 고객센터 화면을 추가했습니다. 공지사항, 자주 묻는 질문 검색, 로그인 고객의 1:1 문의와 답변 확인을 제공합니다.
- 로그인 화면과 오류 화면(401·403·404·500·503·점검)을 추가했습니다. 2단계 인증을 켠 사이트에서는 인증번호 입력 단계로 이어집니다.
- 이 템플릿이 직접 그린 풍경 일러스트를 담았습니다. 외부 이미지나 글꼴 없이 동작합니다.
- 금액은 상점이 정한 통화 단위로 표시됩니다.

### Changed

- 병합된 여행 모듈의 실제 Resource 계약으로 장바구니 금액·번역 상품명·답변·페이지네이션을 연결했습니다. 출발일 이용 불가와 서버 취소 권한을 표시합니다.
- 접수 재시도는 동일 인원·연락처의 키를 유지하고, 연락처 수정은 새 요청 키를 사용합니다. 새로고침 때 저장한 연락처를 복원합니다.
- 이 템플릿의 공개 Service/route/hook 표면은 변경되지 않아 타 확장의 버전 제약 동기화 대상이 없습니다. 초기 0.1.0 구현 통합입니다.
