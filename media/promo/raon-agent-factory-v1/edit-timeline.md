## 오디오

- **A1 음악 베드**: `render/build.sh` 2단계가 ffmpeg 사인파 합성으로 만든 앰비언트 패드. 코드 8개(Cmaj7 · Am7 · Fmaj7 · G6 반복, 마지막 C) × 11초, 3초 교차 페이드, 1.4kHz 로우패스 + 짧은 에코, −22 LUFS 정규화. 외부 음원·샘플 미사용.
- **A2 내레이션**: 이 실행 환경에 음성 합성/녹음 수단이 연결되어 있지 않아 **비어 있다**. [`narration-ko.txt`](narration-ko.txt) 를 SRT 와 같은 타임코드로 녹음한 뒤 A2 에 얹고 A1 을 −6dB 덕킹한다(권장: 차분한 중저음, 기업 발표 톤, 큐당 여유 0.2초).
